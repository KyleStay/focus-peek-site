Focus Peek Privacy Policy

Focus Peek previews images, audio, videos, and galleries without making you leave the current page. It runs in your browser and does not operate user accounts, advertising, tracking, or a publisher-controlled backend. Focus Peek does not collect analytics.

Information Focus Peek processes

Focus Peek examines the current page only to provide its preview features. It may process the current page URL; URLs of links, images, audio, videos, and embeds; visible information associated with a preview target, such as a caption, alt label, display name, username, or nearby user-authored text; media type, dimensions, and gallery items; and the hover, keyboard, pointer, or wheel actions used to control a preview.

The action popup reads the active tab URL locally to show controls for the current site. Focus Peek does not request history permission and does not send browsing history to the publisher. This information is processed locally and is not collected by or sent to the publisher. Visible target text can incidentally contain personally identifiable information or personal communications. Focus Peek does not use it to identify, profile, or contact anyone.

Information stored on your device

Settings are stored in browser extension storage, specifically Chrome's local storage area. They include preview and interaction preferences, keyboard shortcut overrides, pause state, enabled and disabled site lists, and user-authored custom preview rules. Custom rules are user-authored and stored locally. This storage is not a publisher database and is not sent to the publisher.

Local settings remain until you change or reset them, clear Focus Peek's extension storage, or uninstall the extension. Focus Peek does not retain page content, browsing activity, preview history, or interaction events on publisher-controlled systems.

Media and network requests

Focus Peek has access to web pages because it must inspect the target you choose and place a preview on that page. It does not continuously upload page content or browsing activity.

Preview requests are made only after user interaction with a page target. After a hover or keyboard action, a preview may ask the browser to load the selected image, audio, or video; a higher-resolution version identified from the current page or one of your custom rules; a supported provider's embedded player when embeds are enabled; or same-origin Reddit post metadata needed to resolve a Reddit video or gallery.

Those requests go directly from your browser to the media host or player provider, not through a Focus Peek server. The destination may receive ordinary request information such as your IP address, the requested resource, and headers or cookies your browser normally sends there. A same-origin Reddit metadata request may use your existing signed-in session on Reddit. Focus Peek does not read, store, or send authentication credentials to the publisher.

The destination handles these requests under its own privacy policy. Focus Peek does not add a publisher account identifier or receive a copy of the request. Third-party media previews can be disabled, and video-site embeds are optional. Ordinary page metadata is not fetched or used to create previews. Known tracking parameters are removed from preview and open URLs when that setting is enabled.

Extension code and embedded players

Embedded players are provider content displayed in a restricted frame; they are not remotely hosted extension code. All executable extension code is included in the installed package. Focus Peek does not execute remotely hosted code.

Downloads and local files

The downloads permission is used only after you explicitly save the active preview or export a local settings file. Focus Peek does not download media in the background.

Local file pages are supported only when the browser and user allow extension access to those pages. Focus Peek does not preview or open local-file targets from ordinary web pages.

Sharing, sale, and human access

Because Focus Peek does not send page content, browsing activity, settings, or interaction data to the publisher, the publisher does not sell, share, transfer, or allow people to read that information. It is not used for advertising, analytics, credit decisions, or purposes unrelated to Focus Peek's preview features.

Your controls

You can block new third-party preview requests, disable provider embeds, disable Focus Peek on individual sites, use enabled-only mode, require a modifier or keyboard action, pause the extension, reset its settings, or uninstall it. Preview media may remain temporarily in your browser's normal cache or be retained by a media provider under that provider's own practices.

Chrome Web Store Limited Use

Focus Peek's handling of information is limited to providing its single-purpose, user-facing media preview features and complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Local data removal and contact

Focus Peek has no account or publisher-controlled user database, so there is no server-side Focus Peek data to request or delete. To remove locally stored settings, reset Focus Peek, clear its extension storage, or uninstall it.

For questions about this policy, ask a privacy question. Public GitHub issues are visible to everyone, so do not include private URLs, account information, personal data, or sensitive screenshots.
