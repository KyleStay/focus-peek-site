Privacy Policy

Focus Peek runs locally in your browser. It does not operate a tracking, analytics, advertising, account, or publisher-backend service.

Data Focus Peek handles

To provide media previews, Focus Peek handles the current page URL, page media URLs, limited visible page content associated with a preview target (such as a caption), and hover or keyboard activity used to open and control a preview. This website content and browsing activity is processed locally and is not collected by or sent to the publisher.

How the data is used

Focus Peek uses page content and interaction data only to identify the media you asked to preview, render and control that preview, and apply local site and privacy settings. The publisher does not sell, share, or transfer this data and does not use it for advertising, credit decisions, analytics, or any purpose unrelated to the extension's single purpose.

Local storage and retention

Settings, site lists, pause state, and user-authored rules are stored in browser extension storage. Focus Peek does not retain website content, browsing activity, or interaction events on publisher-controlled systems. Local data remains until you edit it, reset the extension, clear extension storage, or uninstall Focus Peek.

Media and third-party providers

Preview requests happen only after user interaction with a page target. When a preview loads a third-party media URL or an optional provider embed, your browser connects directly to that media host or provider. That third party may receive ordinary request information such as your IP address and the requested resource and handles it under its own privacy policy. Focus Peek does not add an account identifier or send the publisher a copy of the request.

Third-party media previews and video-site embeds can be disabled. Video embeds use restricted iframe permissions and conservative referrer policies. Ordinary page metadata is not fetched or used to create previews.

Downloads and local files

The downloads permission is used only when you explicitly save the active previewed media. Local file pages are supported only when Chrome and you allow extension access to those pages. Focus Peek does not preview or open local-file targets from ordinary web pages.

Security and user control

Focus Peek does not execute remotely hosted code. HTTPS media and provider URLs use encrypted transport supplied by the destination. You can block third-party requests, disable embeds, disable Focus Peek on individual sites, pause it, clear its settings, or uninstall it at any time.

Limited Use

Focus Peek's use of information is limited to providing and improving its single-purpose, user-facing media preview features, consistent with the Chrome Web Store User Data Policy's Limited Use requirements.

Contact

For privacy questions or deletion guidance, open a privacy request. Do not include private page URLs, account details, or sensitive screenshots in a public issue.
